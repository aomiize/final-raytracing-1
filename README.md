Submit2 rendered scenes

Rendered image และ Code สำหรับการส่งงานให้ส่งเป็น Github link 
โดย code จะต้องสามารถทำการ Run ได้โดยไม่ติด Error จากการทำงานของ code
ภาพที่ส่ง 1 ภาพต่อ 1 Github repo (ดังนั้นจะต้องแนบ 2 Github repo)

รายละเอียดของรูปภาพที่ส่ง
Resolution : width 3840 pixels
Aspect ratio : 16 : 9
Sample per pixel : ไม่น้อยกว่า 1024

แต่ละรูปภาพควรสร้างจาก Scene ที่แตกต่างกัน

เกณฑ์การให้คะแนนดังนี้
Submission (ส่งรูป และ โค้ดตามกำหนด) – 5% each

Good work (คะแนนความสวยงามของรูปที่ render ออกมา) – 5% each

Scene complexity and/or special effects (ถ้ารูปที่ render มามีองค์ประกอบที่ซับซ้อนเช่น วัตถุจำนวนมาก การจัดวางองค์ประกอบได้น่าสนใจ วัสดุที่ใช้หลากหลาย หรือมี special effects ที่ใส่ลงไปในรูปภาพ) – 2.5% each

New feature (not shown in the teaching codes) (มีการเขียนฟีเจอร์ใหม่ๆ เพิ่มขึ้น) – 2.5% each
